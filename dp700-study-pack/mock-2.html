Q16. A warehouse load must upsert nightly from a staging table into a dimension, generate surrogate keys automatically, empty the staging table afterwards, and deduplicate rows in a session-scoped temp table. Which set uses only supported features? - A. AFTER INSERT trigger on staging, IDENTITY surrogate key, TRUNCATE TABLE on staging - B.
